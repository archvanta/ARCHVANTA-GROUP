# ARCHVANTA AI COMPANY OS

کنسول عملیاتی فارسی و راست‌چین ARCHVANTA GROUP. مدیرعامل انسانی تصمیم‌های مهم را بررسی می‌کند، رئیس دفتر و مدیر عملیات هوش مصنوعی کارها را میان مدیران هماهنگ می‌کند، و مدیران دپارتمان مسئول کیفیت و تحویل خروجی تخصصی‌اند.

فاز اول یک دموی تعاملی است. درخواست‌ها و نقش‌ها نمونه‌اند. تأیید، رد و درخواست اصلاح، وضعیت همان کار و سوابق را در مرورگر به‌روز می‌کنند. تصمیم‌ها فقط در حافظهٔ همان مرورگر و همان نشانی سایت ذخیره می‌شوند. هیچ فرمان، انتشار، هزینه یا وظیفهٔ بیرونی با دکمه‌های دمو اجرا نمی‌شود.

## اجرا و بررسی محلی

به Node.js 22 یا بالاتر نیاز است. پروژه وابستگی نصب‌شدنی ندارد. در ریشهٔ مخزن اجرا کنید.

```sh
node --test
node scripts/build.mjs
node scripts/preview.mjs
```

نشانی پیش‌نمایش [http://127.0.0.1:4173/ARCHVANTA-GROUP/](http://127.0.0.1:4173/ARCHVANTA-GROUP/) است. قرار دادن سایت در این مسیر، حالت معمول یک پروژهٔ GitHub Pages را بازسازی می‌کند.

برای بررسی دستی، صف تصمیم‌ها را باز کنید. یک مورد را تأیید کنید و برای دو مورد دیگر رد و درخواست اصلاح را با دلیل امتحان کنید. شمارندهٔ صف کم می‌شود و وضعیت کارها به «آمادهٔ اجرا»، «رد شده» و «نیازمند اصلاح» تغییر می‌کند. سوابق را باز و صفحه را بازخوانی کنید. یک پنجرهٔ خصوصی تازه برای تکرار سناریو با وضعیت اولیه کافی است.

## انتشار فاز اول

گردش‌کار GitHub Actions روی Pull Request و `main` آزمون مدل و خروجی قابل انتشار را بررسی می‌کند. روی `main` و اجرای دستی از همین شاخه، پس از موفقیت بررسی‌ها فقط `dist/` منتشر می‌شود. در تنظیمات مخزن، منبع Pages باید روی **GitHub Actions** باشد. نشانی انتشار از خروجی job `deploy` مشخص می‌شود. [راهنمای GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

GitHub Pages برای فایل‌های استاتیک دمو است. این سرویس بک‌اند اجرایی دائمی، پایگاه داده، صف، زمان‌بند یا محل امن نگهداری کلید API فراهم نمی‌کند. فایل‌های خروجی برای بازدیدکننده قابل خواندن‌اند. پنل عملیاتی، هویت کاربران، دادهٔ واقعی و کلیدها در فاز بعد به سرویس امن جداگانه منتقل می‌شوند. [محدودیت‌های GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)
